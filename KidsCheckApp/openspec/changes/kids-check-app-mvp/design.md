## Context

全新项目，从零开始构建一个家庭学习打卡 Android 应用。目标用户为一个典型家庭单元：父母（设置任务、审核）、爷爷奶奶（日常打卡操作）、两个孩子（8岁和5岁）。并发量极低（单家庭 2-4 人同时在线），优先开发速度和可维护性。

技术选型已确定：
- Android 客户端：Kotlin + Jetpack Compose
- 后端：Python FastAPI + PostgreSQL
- 文件存储：本地文件系统（MVP 阶段）
- 语音意图解析：大模型 API（通义千问/GPT-4o）

## Goals / Non-Goals

**Goals:**
- 父母可远程管理每周任务模板，爷爷奶奶在现场完成打卡
- 打卡留痕（照片存证），父母可异步审核
- 积分激励机制驱动孩子完成任务
- 界面简洁、字体偏大，爷爷奶奶可轻松操作
- 单台服务器可部署运行

**Non-Goals:**
- 不做 iOS 版本（MVP 仅 Android）
- 不做 AI 图片内容识别（拍照仅作为存证）
- 不做实时推送通知（父母主动查看进度）
- 不做多家庭社交功能
- 不做作业批改或教学内容推荐

## Decisions

### D1: 单体后端 vs 微服务

**选择**: 单体 FastAPI 应用

**理由**: 用户量极小（单家庭），功能边界清晰，单体部署简单、运维成本低。微服务在此场景下是过度设计。

**替代方案**: 微服务拆分（用户服务、任务服务、积分服务）— 增加部署和通信复杂度，无实际收益。

### D2: 认证方案

**选择**: 简化登录（选择用户名 + 输入密码），JWT Token 鉴权

**理由**: 固定 6 个用户，无需注册流程。登录页直接列出用户名供选择，输入密码（统一为 123456）即可。access token 有效期 30 天（家庭私用场景安全性要求低）。

**替代方案**: 无密码直接选人登录 — 过于简单，无法区分设备/防止误操作。

### D3: 每日任务生成策略

**选择**: 服务端定时任务（APScheduler），每天 00:00 UTC+8 批量生成

**理由**: 保证所有用户看到的任务一致，避免客户端时区问题。生成逻辑集中管理，模板变更即时生效。

**替代方案**: 客户端请求时懒生成 — 首次打开会有延迟，且多设备可能产生竞态。

### D4: 照片存储

**选择**: MVP 阶段使用服务器本地文件系统，路径按 `/{family_id}/{child_id}/{date}/{uuid}.jpg` 组织

**理由**: 零额外成本，单家庭照片量可控（每天 5-10 张），服务器磁盘足够。

**替代方案**: OSS/S3 — 增加配置和成本，后续如有多家庭扩展再迁移。

### D5: 语音意图解析架构

**选择**: Android STT 本地转文字 → 后端 `/api/templates/voice` 接口 → 调用大模型解析为结构化指令 → 返回确认卡片

**理由**: STT 在端上免费且延迟低；意图解析放后端方便统一管理 prompt 和模型切换。

**替代方案**: 全部端上处理 — 小模型解析能力不足，复杂指令会失败。

### D6: 数据库 Schema 设计

**选择**: 9 张表（去掉 family 和独立 user 注册），预置种子数据，使用 PostgreSQL 自增 ID

**理由**: 固定用户场景无需复杂身份管理。用户和孩子表通过 migration 种子数据初始化。表结构：user, child, task_template, conditional_task, daily_task, check_in_photo, point_account, point_transaction, reward, reward_redemption。

**替代方案**: NoSQL（如 MongoDB）— 对于结构化强关系数据，查询和一致性保证不如 PostgreSQL。

### D7: 条件任务触发机制

**选择**: 每次打卡完成时检查当日必做任务是否全部完成，若是则自动插入条件任务到 daily_task 表

**理由**: 实时触发体验好，逻辑简单（一次查询判断）。

**替代方案**: 客户端判断后请求 — 可能被绕过，不可靠。

## Risks / Trade-offs

- **[Risk] 服务器单点故障** → Mitigation: MVP 阶段可接受；后续可加 systemd 自动重启 + 定期备份 PostgreSQL
- **[Risk] 照片存储容量增长** → Mitigation: 客户端压缩至 1MB 以下；按月归档旧照片；后续可迁移 OSS
- **[Risk] 大模型 API 不可用导致语音功能降级** → Mitigation: 语音功能非核心路径，失败时 fallback 到手动创建并提示用户
- **[Risk] 定时任务跨天漏生成** → Mitigation: 请求今日任务时若发现无记录则触发补生成逻辑
- **[Risk] 固定密码安全性低** → Mitigation: 家庭私用场景可接受；后端仅在内网或 HTTPS 下暴露；后续可加密码修改功能
